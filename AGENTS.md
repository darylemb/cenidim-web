# AGENTS.md

## Project Structure
- `backend-fastapi/` — FastAPI/Pydantic v2 (production). Reads the
  `letras.db` schema (snake_case; SQLAlchemy ORM under `app/models/`).
- `frontend/` — Vue 3 app (Vite + TypeScript). Entry point: `frontend/src/`.
- `docker/` — `db-init.Dockerfile` + `db-init-entrypoint.sh`: single
  Python+spaCy stage that regenerates `letras.db` from source.
- `data/` — the generated `letras.db` (runtime artifact; regenerated by
  `db-init`, not hand-edited).
- `scripts/build_db.sh` — Builds `letras.db` from CSV + lyrics. Must run before `docker compose up`.
- `scripts/build_db.py` — Python port of the old Go builder (byte-compatible output).
- `scripts/classify_songs.py` — Classifies songs in DB using spaCy (`es_core_news_md`). Runs **after** `scripts/build_db.py` inside `build_db.sh`.
- `scripts/normalize_db.py` — Cleans lyrics, normalizes themes, re-validates lyric↔title match.
- `docs/adr/0001-fastapi-replaces-go.md` — ADR for the cut-over decision.
- `docs/CUTOVER.md` — operator playbook (TL;DR, Phase 7 checklist, Phase 9 retirement).

## Backend (FastAPI — work in progress)
```bash
cd backend-fastapi
uv sync                              # one-time install + lock
PYTHONPATH=. uv run pytest tests/    # 171 tests, 95.93% coverage (95% gate)
uv run ruff check app/ tests/        # lint (clean)
uv run mypy app/                     # type check (strict, ignore_missing_imports)
uv run uvicorn app.main:app --port 8000 --reload
./scripts/smoke.sh http://localhost:8000  # post-boot health check
# Migrations
uv run alembic upgrade head           # apply pending migrations
uv run alembic revision --autogenerate -m "..."  # create new migration
# OpenAPI
uv run python scripts/generate_openapi.py  # refresh openapi.json
```

Docker (default = FastAPI):
```bash
docker compose up --build          # FastAPI on :8000
# (The Go rollback compose was removed in Phase 9.)
backend-fastapi/scripts/smoke.sh http://localhost:8000
```
- Reads the `letras.db` SQLite schema
  (snake_case column names; SQLAlchemy ORM models under
  `app/models/`).
- Auth: `app/services/auth.py` (password hashing via sha256+bcrypt,
  JWT issue/verify via python-jose, refresh-token rotation via
  `RefreshTokenRevocation` table).
- Admin: `app/routers/admin.py`; viewer/editor/admin tiers backed by
  `require_role("...")` factory in `app/deps.py`.
- Resend + dev outbox: `app/services/email.py`.
- Test conftest (`tests/conftest.py`) shares a single StaticPool
  in-memory engine between the FastAPI app and direct ORM seed
  helpers (`make_user`, `make_admin`, `make_email_outbox`).
- Coverage gate is `95%`. The remaining ~5% lives in the Resend send
  path and the audit-log warning branches that aren't reachable
  without breaking the in-memory engine mid-request.

## Database Build
```bash
./scripts/build_db.sh
```
Requires: Python with `bcrypt` and spaCy (`es_core_news_md` model).
Sets `ADMIN_PASS` env var to create initial admin user.
The three-step process: (1) `scripts/build_db.py` builds SQLite from
`db_fonografia.csv` + `LetrasTXT/` (Python port of the old Go builder,
byte-compatible output), (2) Python/spaCy classifies each song +
writes `song_stats`, (3) `scripts/normalize_db.py` cleans lyrics,
normalizes themes and re-validates the lyric↔title match.

## Frontend (Vue 3 + TypeScript)
```bash
cd frontend
npm install              # Install dependencies
npm run dev             # Dev server on :5173 (Vite)
npm run build           # TypeScript check + Vite build
npm run typecheck       # vue-tsc --noEmit only
npm run lint            # ESLint
npm run lint:fix        # ESLint --fix
npm run test            # Vitest watch mode
npm run test -- --run   # Tests once (CI)
npm run test:coverage   # Coverage report
```
- **Node 24** required
- Build tool: **Vite** (replaces react-scripts)
- Charts: **vue-chartjs** (Chart.js wrapper)
- State: **Pinia** stores (`src/stores/`: auth, search, ui)
- Routing: **Vue Router 4** (routes in `src/router/`)
- TypeScript **strict mode**
- Tests: **Vitest + Vue Test Utils**
- CSS: global `src/assets/main.css` + `<style scoped>` per component

```bash
./scripts/run_ci_local.sh
```
Secuencia: backend lint+test → frontend lint+typecheck+test → Docker build+health

## CI (GitHub Actions)
- **Frontend**: `npm ci` → `npm run lint` → `npm run build` (includes typecheck) → `npm run test -- --run`
- **Backend**: `ruff check` → `pytest` (FastAPI) + openapi drift guard
- **Docker**: `docker compose build` → `docker compose up -d` → `curl localhost:8000/healthz` → `docker compose down`

## Docker
- `db-init` sidecar: single Python+spaCy stage (`docker/db-init.Dockerfile`)
  that regenerates `letras.db` (build → classify → normalize).
- Backend: `backend-fastapi/Dockerfile` (uv-managed deps, non-root).
- `docker compose up --build -d` builds everything including DB initialization
- Frontend served via nginx-unprivileged on port 80
- spaCy model: `es_core_news_md`

## Pre-commit Hooks
- Ruff (lint + format) for Python files
- Mypy for Python type checking (requires `pydantic`, `fastapi`, `uvicorn` as extra deps)
- Standard hooks: trailing whitespace, end-of-file fixer, YAML check, large-file check
